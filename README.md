MCP Server Implementation – HR Leave Balancer Chatbot
Overview

This project contains an experimental implementation of an MCP (Model Context Protocol) server for an HR Leave Balancer Chatbot. The MCP server was implemented by referring to standard MCP examples to understand server structure, tool exposure, and model interaction.
